# Su Erdemir — Portfolio Website

## Project
Child talent (model/actor/commercial) portfolio website for Su Erdemir, age 10.

## Stack
- **SSG:** Eleventy (11ty)
- **CSS:** Tailwind CSS
- **Animations:** GSAP + ScrollTrigger (parallax, smooth scroll, reveal animations)
- **Deploy:** Vercel

## Design
- Black & white color palette
- Fullscreen sections with smooth scroll
- Parallax effects throughout
- Modern, minimal typography-driven design
- Mobile-first responsive

## Sections
1. Hero — fullscreen with name + tagline
2. About — bio, stats (age, height, etc.)
3. Gallery — photo grid with lightbox
4. Reel — video section
5. Resume — credits & training
6. Contact — professional contact form

## Commands
```bash
npm install        # install deps
npx @11ty/eleventy --serve  # dev server
```
